Embed in 2 lines

No build step. No npm install. Just a script tag with your API key. Shadow DOM keeps our styles out of your way.

index.html 
<!-- Add this where you want the search widget -->
<div id="lucidrag-search"></div>
<script src="https://search.lucidrag.com/widget/lucidrag-search.js"
        data-api-key="lrag_your_key_here"
        data-mode="both"
        data-theme="auto">
</script>
data-mode "search" | "chat" | "both"
data-theme "light" | "dark" | "auto"
data-position "inline" | "floating"

How we compare
Chatbase charges $39/mo just to remove their badge. Kapa.ai starts at ~$99/mo. Inkeep at ~$200/mo. My AskAI at $149/mo for 1K conversations. We start at $19/mo with no badge, 200 chats/day, and 100 docs.

Clean REST API

Use the widget or call the API directly. Your choice.

Search API 
// POST /api/saas/search
curl -X POST https://search.lucidrag.com/api/saas/search \
  -H "X-Api-Key: lrag_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{"query": "how to configure auth"}'

// Response
{
  "results": [
    {
      "title": "Authentication Guide",
      "text": "Configure OAuth in config.yaml...",
      "score": 0.89,
      "pageOrSection": "Getting Started"
    }
  ],
  "totalResults": 12,
  "responseTimeMs": 45
}
Chat API (SSE Streaming) 
// POST /api/saas/chat/stream
curl -N -X POST https://search.lucidrag.com/api/saas/chat/stream \
  -H "X-Api-Key: lrag_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{"query": "explain the auth flow"}'

// Server-Sent Events
data: {"type":"sources", "sources":[...]}
data: {"type":"text", "text":"Based on your docs..."}
data: {"type":"text", "text":" the auth flow uses..."}
data: [DONE]
